# Prompt Gambar: Batch 1 (Judul, Menu, Misi 1)

## Cara pakai

1. Pakai tool yang bisa menerima gambar referensi (ChatGPT, Gemini, atau sejenisnya).
2. Tiap prompt punya daftar **Referensi**. Lampirkan file itu dari folder `assets-src/referensi/`, lalu tempel teks prompt-nya apa adanya.
3. Minta ukuran landscape 16:9, setinggi mungkin resolusinya.
4. Simpan hasilnya ke `assets-src/masuk/` dengan **nama file persis** seperti tertulis. PNG atau JPG sama saja.

## Cek sebelum disimpan

- Nggak ada tulisan, angka, atau logo di gambar.
- Tangan wajar, jari nggak aneh.
- Gaya lembut seperti sampul, tanpa garis tepi hitam tebal.
- Lembar tokoh dan objek: latarnya **putih polos** dan antar sosok nggak saling menempel. Jangan pakai latar transparan atau kotak-kotak.

Kalau hasilnya melenceng, ulang sekali dengan tambahan: `Match the first reference image's style more closely: soft shading, fine grain, no outlines.`
